本書は `index_codex.html` に実装された機能、画面、データ処理および制約を記述する。構想上の将来機能ではなく、成果物の現行実装を仕様の基準とする。

## 2. 目的

Wikiwalkerは、Wikipediaの記事を星、記事間の関連を星同士のつながりとして可視化する3Dブラウザーである。利用者はキーワード検索から任意の記事を起点にし、関連する記事星やカテゴリ星団を選択しながらWikipediaの知識空間を探索できる。

設計上の主眼は次のとおりである。

- 検索、選択、探索をひとつの画面内で完結させる。
- 記事の取得中も、可能な限りグラフの回転、移動、ズームおよび既存ノードの選択を妨げない。
- 関連記事を無制限に表示せず、上位記事とカテゴリ星団へ整理して視認性を保つ。
- サーバーやビルド工程を必要とせず、単一HTMLをブラウザーで直接実行できるようにする。
- Wikipedia本文の出典、ライセンスおよび商標に関する表示を画面上へ常設する。

## 3. 対象範囲

### 3.1 提供する機能

- Wikipedia言語版の自動選択および手動切替
- インクリメンタル記事検索
- 検索候補のマウスおよびキーボード選択
- 選択記事の概要表示
- 類似記事の取得および3Dグラフへの逐次追加
- 関連記事のカテゴリ星団への集約
- 記事星およびカテゴリ星団の展開
- 記事選択履歴の前後移動
- 3Dグラフの回転、平行移動およびズーム
- Wikipedia原文への遷移
- 通信状況およびエラー状況の表示

### 3.2 対象外

- Wikipedia記事の編集
- ログインや利用者アカウントの管理
- グラフの保存、共有またはエクスポート
- 複数言語版の記事を同一グラフ上で統合する処理
- Wikipedia本文全体の表示
- オフラインでの記事検索および記事取得
- サーバー側のキャッシュ、プロキシまたはデータベース

## 4. 実行環境と依存関係

### 4.1 実行方式

`index_codex.html` をモダンブラウザーで開いて実行する。ローカルHTTPサーバー、パッケージインストール、トランスパイルおよびビルドは不要である。

Wikipedia APIおよび外部JavaScriptライブラリの取得にはインターネット接続を必要とする。

### 4.2 外部ライブラリ

| ライブラリ | バージョン | 用途 |
| --- | --- | --- |
| `three` | 0.186.0 | WebGLによる3Dオブジェクト生成 |
| `3d-force-graph` | 1.80.0 | 3D力学グラフ、カメラ、操作制御 |
| `three-spritetext` | 1.10.0 | 3D空間内の記事タイトル表示 |

すべて `https://esm.sh/` からES Moduleとして読み込む。バージョンは成果物内で固定する。

### 4.3 ブラウザー要件

以下を利用できるブラウザーを対象とする。

- WebGL
- ES ModulesおよびImport Maps
- Fetch APIおよびAbortController
- `dialog` 要素
- CSS `backdrop-filter`。未対応時も基本操作には影響しない。
- `localStorage`

## 5. 画面仕様

アプリケーションは単一画面で構成する。グラフを全画面背景として、その上に操作UIを重ねる。

### 5.1 初期案内

記事未選択時は画面中央に次のメッセージを表示する。

- 見出し: 「知識の宇宙を、歩く。」
- 説明: Wikipediaのつながりを星図として辿る旨

最初の記事を正常に取得した時点で案内をフェードアウトし、グラフ凡例を表示する。言語切替でグラフを初期化した場合は再び表示する。

### 5.2 ヘッダー

画面上部に以下を表示する。

| 項目 | 動作 |
| --- | --- |
| ブランド | アプリ名「Wikiwalker」と副題を表示する。狭い画面では省略する。 |
| 言語ボタン | 選択中のWikipedia言語コードを大文字で表示し、押下時に言語選択ダイアログを開く。 |
| 検索入力 | 記事タイトルまたはキーワードを入力する。入力後260ミリ秒のデバウンスを経て検索する。 |
| 検索消去 | 入力値と検索候補を消去し、入力欄へフォーカスを戻す。入力が空の場合は非表示とする。 |
| Prev | 記事選択履歴のひとつ前へ移動する。移動先がない場合は無効にする。 |
| Next | Prevで戻る前の記事へ移動する。移動先がない場合は無効にする。 |
| 履歴位置 | `現在位置 / 履歴数` を表示する。狭い画面では省略する。 |

### 5.3 検索候補

- 検索結果を最大8件表示する。
- 各行には通し番号、記事タイトルおよびAPIの検索抜粋を表示する。
- APIが返す抜粋のHTMLは一度DOMへ展開し、テキストのみを表示する。
- マウスポインターを置いた行を選択状態にする。
- `ArrowDown` と `ArrowUp` で選択行を循環移動する。
- `Enter` で選択行を決定する。
- `Escape` または検索領域外のクリックで候補を閉じる。
- 新たな検索を開始した場合は、直前の未完了検索を中止する。

### 5.4 言語選択ダイアログ

- 利用可能なWikipedia言語版をグリッド表示する。
- 言語名または言語コードによる部分一致絞り込みを提供する。
- 初期一覧は最大48件、絞り込み時は最大120件を表示する。
- 日本語、英語など主要12言語を一覧の先頭側へ配置する。
- 現在の言語を選択状態として表示する。
- 言語変更時は検索、グラフ、記事詳細および履歴を初期化する。

### 5.5 3Dグラフ

グラフは画面全体へ表示し、次の操作を提供する。

| 操作 | 結果 |
| --- | --- |
| ドラッグ | グラフを回転する。 |
| ShiftまたはCtrlを押しながらドラッグ | グラフを平行移動する。 |
| マウスホイールまたはトラックパッド | ズームする。 |
| 記事星をクリック | その記事を選択して中央へ注視し、未探索なら関連記事を取得する。 |
| カテゴリ星団をクリック | 星団を選択して中央へ注視し、内包する記事星を展開する。 |

記事星は球体、カテゴリ星団は八面体として描画する。選択中のノードは明色、大きい半径、ハローおよび強調ラベルで表す。深度ごとに記事星の色を変更する。

### 5.6 記事詳細パネル

画面右下へ固定表示する。記事星選択時には以下を表示する。

- 種別: `Wikipedia article`
- 探索深度: `ORBIT NN`
- 記事タイトル
- 記事冒頭のプレーンテキスト抜粋
- Wikipedia原文へのリンク
- 未探索、探索中または探索済みを表す補助情報

抜粋がノードにない場合はスケルトン表示を出し、記事情報を追加取得する。長い抜粋はパネル内部だけをスクロールする。

カテゴリ星団選択時には以下を表示する。

- 種別: `Category constellation`
- 内包する記事星数
- 星団名
- 星団の説明
- 内包記事のうち最大8件のタイトル
- 展開状態

カテゴリ星団はWikipedia上の単一記事ではないため、原文リンクを非表示にする。

### 5.7 状態表示

画面上部中央へ一時的なピル型メッセージを表示する。

- 検索または探索中は発光するドットを表示する。
- 成功メッセージは指定時間後に自動で隠す。
- エラー時はドットを赤色にし、自動で隠す。
- 状態表示は `role="status"` と `aria-live="polite"` を持つ。

### 5.8 凡例と操作案内

記事選択後、左上に記事星とカテゴリ星団の形状凡例を表示する。画面下中央に3D操作方法を常時表示する。ただし狭い画面では操作案内を非表示にする。

### 5.9 権利表示

画面左下へ常時、以下を表示する。

- 記事テキストの `CC BY-SA 4.0` 表示とライセンスへのリンク
- 選択中言語版Wikipediaへの出典リンク
- Wikipedia商標とWikimedia Foundationとの非提携表示

記事詳細では対象記事の原文URLも提示し、記事単位の出典へ到達できるようにする。

## 6. 画面状態と遷移

### 6.1 主要状態

| 状態 | 表示内容 | 遷移条件 |
| --- | --- | --- |
| 初期状態 | 初期案内、検索、言語選択 | 検索文字入力で検索候補状態へ遷移 |
| 検索候補状態 | 検索候補リスト | 候補選択で記事読込状態へ遷移 |
| 記事読込状態 | 状態メッセージ。既存操作は原則維持 | 取得成功で探索状態、失敗で直前状態へ戻る |
| 探索状態 | 記事星、関係線、詳細、履歴、凡例 | 記事星または星団の選択でグラフを追加展開 |
| 言語選択状態 | モーダルダイアログ | 言語決定で初期状態へ戻る |

### 6.2 新しい検索結果からの記事選択

1. 選択タイトルを検索入力へ設定する。
2. 既存の記事取得および関連記事取得を中止する。
3. 選択記事の情報と抜粋を取得する。
4. 既存グラフと履歴を初期化する。
5. 選択記事を深度0のルート記事星として追加する。
6. 詳細パネルを表示し、履歴へ追加する。
7. 選択記事をカメラ中央へ移動する。
8. 関連記事の取得と逐次表示を開始する。

### 6.3 既存記事星の選択

1. 直前の選択ノードの座標固定を解除する。
2. 選択した記事星の現在座標を固定する。
3. グラフを初期化せず、選択記事星をカメラ中央へ移動する。
4. 記事詳細を更新する。
5. 通常操作による選択なら履歴へ追加する。
6. 未探索のノードなら関連記事を取得する。

### 6.4 履歴移動

- 履歴は記事ノードIDの配列と現在位置で管理する。
- PrevまたはNextでは既存グラフを変更せず、対応する記事星を再選択する。
- 履歴移動自体は新しい履歴を追加しない。
- Prevで過去へ移動後、別の記事星を通常選択した場合は現在位置より後ろの履歴を破棄し、新しい分岐として追加する。
- カテゴリ星団の選択は記事選択履歴へ追加しない。

## 7. Wikipedia API仕様

### 7.1 共通仕様

各言語版のAction APIを使用する。

```text
{Wikipedia base URL}/w/api.php
```

共通パラメーターは以下とする。

| パラメーター | 値 |
| --- | --- |
| `action` | `query` |
| `format` | `json` |
| `formatversion` | `2` |
| `origin` | `*` |
| `maxlag` | `5` |

HTTPエラーおよびAPIレスポンス内の `error` は例外として扱う。

### 7.2 記事検索

`list=search` を用いる。

| パラメーター | 値 |
| --- | --- |
| `srsearch` | 利用者の入力文字列 |
| `srnamespace` | `0` |
| `srlimit` | `8` |
| `srprop` | `snippet|titlesnippet` |

### 7.3 記事詳細

`titles` と複数の `prop` を用いる。

| パラメーター | 値 |
| --- | --- |
| `prop` | `info|extracts|pageprops` |
| `inprop` | `url` |
| `redirects` | `1` |
| `exintro` | `1` |
| `explaintext` | `1` |
| `exsectionformat` | `plain` |
| `titles` | 対象記事タイトル |

### 7.4 関連記事

CirrusSearchの `morelike:` 検索を `generator=search` として使用し、類似度順の候補と表示情報を一括取得する。

| パラメーター | 値 |
| --- | --- |
| `generator` | `search` |
| `gsrsearch` | `morelike:{記事タイトル}`。空白は `_` へ置換する。 |
| `gsrnamespace` | `0` |
| `gsrlimit` | `20` |
| `prop` | `info|extracts|pageprops|categories` |
| `inprop` | `url` |
| `exintro` | `1` |
| `explaintext` | `1` |
| `exchars` | `220` |
| `exlimit` | `20` |
| `cllimit` | `5` |
| `clshow` | `!hidden` |

存在しないページおよび `pageprops.disambiguation` を持つ曖昧さ回避ページは候補から除外する。

### 7.5 言語一覧

Meta-WikiのSite matrixを使用する。

```text
https://meta.wikimedia.org/w/api.php
```

主要パラメーターは `action=sitematrix`、`smtype=language`、`smsiteprop=url|code`、`smlimit=max` とする。各言語グループから次をすべて満たすサイトだけを採用する。

- `site.code === "wiki"`
- `closed`、`private`、`fishbowl` のいずれも付いていない。
- HTTPSの `wikipedia.org` 配下である。

取得結果は `localStorage` の `wikiwalker-sites` へ取得時刻とともに保存し、7日間再利用する。取得に失敗した場合は、日本語、英語、ドイツ語、フランス語、スペイン語および中国語のフォールバック一覧を使用する。

選択言語コードは `wikiwalker-language` へ保存する。起動時は保存済み言語、`navigator.languages`、`navigator.language` の順で利用可能サイトと照合し、一致しなければ日本語版を使用する。

## 8. 関連記事の整理仕様

APIから取得した最大20件をそのまま表示せず、以下の決定論的な手順で整理する。

1. 起点記事自身を候補から除外する。
2. APIの類似度順位を優先して昇順に並べる。
3. 上位10件を通常の記事星として直接表示する。
4. 残りを、各記事に付与された最初の有効カテゴリでグループ化する。
5. 管理用途と判断できるカテゴリ名を除外する。
6. カテゴリがない記事は「そのほかの関連領域」へ入れる。
7. グループ数が3以下ならそのまま星団化する。
8. グループ数が4以上なら上位2グループを個別星団とし、残りを「そのほかの関連領域」星団へ統合する。

管理用途の判定には、カテゴリ名に「記事」「出典」「参照」「識別子」「曖昧さ」「一覧」「ページ」「ウィキペディア」「CS1」または「Webarchive」を含むかを用いる。また34文字以上のカテゴリ名は星団名に使用しない。

記事星は115ミリ秒間隔、星団内の記事星は100ミリ秒間隔で1件ずつ追加する。この逐次追加により、取得完了後の変化を利用者が追えるようにする。

## 9. グラフデータ仕様

### 9.1 記事ノード

| プロパティ | 内容 |
| --- | --- |
| `id` | `{言語コード}:{pageid}` |
| `pageId` | WikipediaページID |
| `title` | 記事タイトル |
| `extract` | 記事冒頭のプレーンテキスト |
| `url` | Wikipedia原文URL |
| `categories` | カテゴリ名の配列 |
| `rank` | 類似検索の順位。ない場合は999。 |
| `type` | `article` |
| `depth` | ルートからの探索深度 |
| `expanded` | 関連記事を展開済みか |
| `loading` | 関連記事を取得中か |
| `x`, `y`, `z` | 3D座標 |

同一言語版の同一ページIDは単一ノードへ統合する。

### 9.2 カテゴリ星団ノード

| プロパティ | 内容 |
| --- | --- |
| `id` | `cluster:{親ノードID}:{カテゴリ名}` |
| `title` | カテゴリ名または統合名 |
| `type` | `cluster` |
| `members` | 内包する記事データの配列 |
| `depth` | 親記事の深度 + 1 |
| `expanded` | 内包記事を展開済みか |

### 9.3 エッジ

| プロパティ | 内容 |
| --- | --- |
| `source` | 親ノードID |
| `target` | 子ノードID |
| `kind` | `article` または `cluster` |

同じ2ノード間の辺は方向にかかわらず重複追加しない。記事辺と星団辺は色および長さを変えて描画する。

## 10. クラス設計

### 10.1 `WikipediaClient`

Wikipedia APIとの通信、言語サイト解決、レスポンスの内部データ形式への変換を担当する。

| メソッド | 責務 |
| --- | --- |
| `request` | 共通パラメーターを付加してAction APIを呼び出す。 |
| `search` | 検索候補を取得する。 |
| `getArticle` | 記事情報と冒頭抜粋を取得する。 |
| `getRelated` | 類似記事、抜粋およびカテゴリを取得する。 |
| `normalizePage` | APIページを記事ノード用データへ変換する。 |
| `loadSites` | Site matrixまたはキャッシュから言語一覧を取得する。 |
| `chooseBrowserLanguage` | 保存値とブラウザー言語から初期言語を決定する。 |
| `selectLanguage` | 言語を切り替えて保存する。 |

### 10.2 `GraphStore`

記事ノード、カテゴリ星団およびエッジを保持し、重複を防止する。

### 10.3 `GraphRenderer`

3Dグラフの生成、ノード外観、力学パラメーター、リサイズ、選択強調およびカメラ移動を担当する。

主な描画パラメーターは次のとおりである。

- 力学レイアウトの速度減衰: `0.62`
- 計算継続時間: `9000ms`
- 記事辺の標準距離: `105`
- 星団辺の標準距離: `82`
- カメラと選択ノードの距離: `145`
- カメラ移動時間: `850ms`

### 10.4 `SearchController`

検索入力、デバウンス、通信中止、候補描画、キーボード操作および選択通知を担当する。

### 10.5 `WikiwalkerApp`

各クラスを統合し、画面状態、記事選択、グラフ展開、言語変更、詳細パネルおよび履歴を管理する。

## 11. 非同期処理と競合制御

- 検索リクエストごとにAbortControllerを作成し、新しい入力時に直前の検索を中止する。
- 新しい検索結果から開始する場合は、進行中の記事取得と関連記事取得を中止する。
- 別の記事星を展開する場合は、直前の関連記事取得を中止する。
- 取得済みノードは再取得、再展開しない。
- 詳細取得の完了時に選択対象が変わっていた場合、取得結果で現在の詳細パネルを上書きしない。
- API取得中でも、既に表示されているグラフに対するカメラ操作を禁止しない。

## 12. エラー処理

| 発生箇所 | 利用者への表示・動作 |
| --- | --- |
| 検索API失敗 | 候補欄へ「検索できませんでした。通信を確認してください。」と表示する。 |
| 記事取得失敗 | 状態表示へAPIエラーまたは取得失敗を表示する。既存グラフは保持する。 |
| 関連記事0件 | 「この先の関連記事は見つかりませんでした」と表示し、展開済みにする。 |
| 関連記事取得失敗 | 「関連記事の取得に失敗しました」と表示し、再選択時に再試行可能な状態を保つ。 |
| 詳細取得失敗 | 詳細パネルへ「概要を取得できませんでした。」と表示する。 |
| Site matrix失敗 | 組み込みの6言語一覧へフォールバックする。 |

通信エラーに対する自動再試行は行わない。利用者の再操作を再試行契機とする。

## 13. レスポンシブ仕様

### 13.1 幅840px以下

- ブランド表示を非表示にする。
- 検索と履歴を2列で配置する。
- 詳細パネルの最大高を画面高の43%とする。
- 画面下の操作案内を非表示にする。
- 言語一覧を2列にする。

### 13.2 幅540px以下

- ヘッダーを1列にする。
- 履歴操作を検索欄の下、画面右側へ固定する。
- 履歴位置表示と言語ボタン内の地球アイコンを省略する。
- 詳細見出しを縮小する。

## 14. アクセシビリティ

- 検索欄、各ボタン、グラフへ日本語のアクセシブル名を設定する。
- 検索候補へ `listbox`、各候補へ `option` を設定する。
- 検索候補の選択状態を `aria-selected` で通知する。
- 記事詳細と状態メッセージを `aria-live="polite"` とする。
- キーボードだけで検索候補を選択できるようにする。
- `prefers-reduced-motion: reduce` の場合はアニメーション時間を実質的に無効化する。
- 色だけでなく形状、サイズ、ラベルおよび位置でもノード種別と選択状態を区別する。

## 15. セキュリティとプライバシー

- APIから得た検索抜粋はHTMLのまま挿入せず、テキストへ変換して表示する。
- 記事タイトル、概要、カテゴリ名は `textContent` でDOMへ設定する。
- 外部リンクは `target="_blank"` と `rel="noopener noreferrer"` を使用する。
- 認証情報、Cookieおよび利用者固有情報をWikipedia APIへ送信しない。
- `localStorage` へ保存するのは言語一覧キャッシュ、取得時刻および選択言語コードだけである。

## 16. パフォーマンス方針

- 検索入力を260ミリ秒デバウンスする。
- 関連記事は1回の展開につき最大20件とする。
- 通常記事星を最大10件、カテゴリ星団を最大3件へ抑える。
- 星団を選択するまで内包記事を描画しない。
- 記事星は最大8件ずつ星団から展開する。
- ノードとエッジは配列、ノード検索はMapで管理する。
- Site matrixは7日間キャッシュする。
- 力学シミュレーションの減衰を高め、長時間の揺れを抑える。

## 17. 既知の制約

- 外部ライブラリとWikipedia APIを使用するため、完全なオフライン動作には対応しない。
- 類似記事はCirrusSearchの `morelike:` 結果であり、本文中に直接リンクが存在することを保証しない。
- 関連候補は最大20件であり、すべての関連記事を網羅しない。
- カテゴリ取得には1記事あたり最大5件を使用し、APIの継続取得は行わない。
- 星団の分類は最初の有効カテゴリを使う簡易方式であり、厳密な意味分類ではない。
- グラフ状態はページ再読込で失われる。
- 一部のブラウザーやローカルファイル実行ポリシーでは、外部ES Moduleの読み込みが制限される場合がある。

## 18. 受入条件

以下をすべて満たした場合、主要機能が動作していると判断する。

1. `index_codex.html` 単体を開いて初期画面が表示される。
2. 検索文字を入力するとWikipediaの検索候補が表示される。
3. マウスまたは上下キーとEnterで候補を選択できる。
4. 選択記事星、概要およびWikipedia原文リンクが表示される。
5. 関連記事が段階的に追加され、10件を超える候補は最大3個のカテゴリ星団へ整理される。
6. 記事星を選択すると既存グラフを維持したままカメラ中央へ移動する。
7. 未探索の記事星を選択すると、その記事の関連候補が追加される。
8. カテゴリ星団を選択すると内包記事星が展開される。
9. PrevおよびNextで記事選択履歴を移動できる。
10. ドラッグ、ShiftまたはCtrl併用ドラッグ、ホイールでグラフを操作できる。
11. 言語を変更すると検索、グラフ、詳細および履歴が初期化され、以降のAPIが新しい言語版を使用する。
12. Wikipediaの出典、CC BY-SA 4.0および商標に関する表示が画面左下に常時表示される。
13. 狭い画面で検索、履歴および詳細パネルが画面外へはみ出さず操作できる。
