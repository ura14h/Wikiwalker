# アプリのコンセプト

- アプリの名前は「Wikiwalker」。
- アプリのコンセプトは「Wikipedia宇宙の中を記事星を辿って散策する」。
- Wikipediaが保有する記事に対して、マウスを使って簡単に概要を見たり関連リンクを辿ったりできるグラフィカルなブラウザー。

## 動作要件

- アプリはとてもポータブルなものにする。具体的には、単一HTMLにまとまっていてローカル環境でサーバーレスでブラウザのみで動作する。
- 外部ライブラリはインターネットから読み込んでも良い。

## 画面の表示

- 画面の表示項目と遷移は [アプリのストーリーボード](storyboard.md) を参考にする。
- Wikipedia宇宙の表示と操作は [グラフ UI サンプル](refs/graph-ui-sample.html) を参考にする。
- Wikipediaの権利表示は厳守しないといけない。画面左下に小さく常時表示する。
- 画面のデザインテーマは、宇宙・SF・辞典・シンプル。

## 記事の取得

- Wikipediaの記事を取得するAPIは [Wikipedia API 仕様書](refs/wikipedia-api.md) を参考にする。

- Wikipediaの利用制限事項は厳守しないといけない。

## 留意事項

### 表示の応答性

- マウス操作やキーボード入力への応答は常に軽快であること。
- 記事データ取得中にもできるだけ操作禁止区間がないようにすること。

### 記事データと記事星の意味変換

- 関連記事を大量に持つ記事をそのまま表示すると画面がノードとエッジで飽和してしまう。
- 大量の関連記事は決定論的な手法で集約したノードで代替表示する。カテゴリや関心領域の単位で集約する。
- 関連記事を集約する手法は [Wikipedia 関連記事の可視化手法](refs/wikipedia-graph.md) を参考にする。

### 成果物の規模

- HTMLの内容は過度にエンジニアリングしない。
- バニラ Javascript を使用する。処理責務の分割設計はOOPを採用する。
- コードリーディングする人間の認知負荷を下げる工夫をする。
